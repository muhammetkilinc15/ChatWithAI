# SemanticKernel-AI-Mesajlaşma

**SemanticKernel-AI-Mesajlaşma** projesi, ASP.NET Core API ile arka uç işlemlerini yöneten ve MVC ile kullanıcı dostu bir ön yüz sunan, anlık yapay zeka destekli bir mesajlaşma sistemini entegre eden bir uygulamadır. Bu proje, Semantic Kernel kullanarak, kullanıcıların yapay zeka ile gerçek zamanlı etkileşimde bulunmalarını sağlar.

## Özellikler:
- **Gerçek Zamanlı Yapay Zeka Mesajlaşma**: Anlık olarak yapay zeka ile sohbet etme imkanı.
- **ASP.NET Core API**: Yapay zeka modeli ile iletişimi yönetmek ve kullanıcı verilerini işlemek için kullanılan arka uç.
- **MVC Ön Yüz**: Kullanıcıların yapay zeka ile kolayca iletişim kurabilmesini sağlayan kullanıcı dostu bir arayüz.
- **Semantic Kernel Entegrasyonu**: Yapay zeka modelleriyle daha iyi sohbet anlayışı ve bağlam takibi sağlamak için kullanılır.

## Kullanılan Teknolojiler:
- **ASP.NET Core API** (arka uç geliştirme)
- **MVC** (ön yüz geliştirme - Model-View-Controller)
- **Semantic Kernel** (Yapay Zeka model entegrasyonu)
- **Gerçek Zamanlı İletişim** (SignalR veya WebSockets kullanılarak)
